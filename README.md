# Anatomy Lab — Launch Website

Sitio público de lanzamiento de **Anatomy Lab by Duarte & Barros**.

**Sitio:** https://aduartech81.github.io/anatomy-lab/

## Alcance de esta versión

- Presentación de Anatomy Lab como unidad de negocio.
- Líneas de desarrollo: modelos anatómicos, simulación, formación e investigación.
- Proyecto fundador de simulación facial por capas.
- Presentación de los cofundadores.
- Captación de universidades, centros de simulación, grupos de investigación, empresas y aliados.
- Formulario que prepara una solicitud dirigida a `aduartech@gmail.com`.
- Diseño responsive para escritorio y dispositivos móviles.
- SEO técnico básico, Open Graph, sitemap y robots.txt.

## Tecnología

Sitio estático en HTML, CSS y JavaScript, optimizado para una publicación rápida y mantenimiento sencillo.

Cada cambio enviado a la rama `main` activa la publicación automática mediante GitHub Pages.
