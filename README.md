# Anatomy Lab — Launch Website

Sitio público de lanzamiento de **Anatomy Lab by Duarte & Barros**.

**Sitio:** https://aduartech81.github.io/anatomy-lab/

## Objetivo

Presentar Anatomy Lab como una unidad de innovación y desarrollo en simulación anatómica, mostrar el proyecto fundador y captar solicitudes de universidades, centros de simulación, grupos de investigación, empresas y aliados estratégicos.

## Contenido de la versión publicada

- Hero anatómico de alto impacto con selector conceptual de sistemas.
- Líneas Anatomy Models, Simulation, Academy y Research.
- Proyecto fundador Facial Anatomy Simulation System.
- Rutas de trabajo: prototipos, experiencias educativas, investigación y alianzas.
- Equipo científico:
  - Andrés Duarte Chaves.
  - Adriana Milena Barros Meza.
  - Gerardo José Valencia Villa.
- Contacto directo por correo, WhatsApp e Instagram.
- Formulario estático que prepara una solicitud por WhatsApp.
- Diseño responsive, SEO básico y despliegue automático con GitHub Pages.

## Tecnología

HTML, CSS y JavaScript sin dependencias de compilación. El sitio se publica automáticamente desde la rama `main` mediante GitHub Actions y GitHub Pages.
