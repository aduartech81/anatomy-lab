# Anatomy Lab — Launch Website

Sitio público de lanzamiento de **Anatomy Lab by Duarte & Barros**.

**URL pública:** https://aduartech81.github.io/anatomy-lab/

## Alcance

- Landing de posicionamiento para presentar Anatomy Lab como unidad de negocio.
- Hero anatómico de alto impacto con interacción conceptual por sistemas.
- Líneas Anatomy Models, Anatomy Simulation, Anatomy Academy y Anatomy Research.
- Proyecto fundador: Facial Anatomy Simulation System.
- Equipo científico: Andrés Duarte Chaves, Adriana Milena Barros Meza y Gerardo José Valencia Villa.
- Contacto directo por correo, WhatsApp e Instagram.
- Formulario que prepara la solicitud del visitante en WhatsApp.
- Diseño responsive, accesibilidad básica, SEO y datos estructurados.
- Despliegue automático mediante GitHub Actions y GitHub Pages.

## Estado del producto

Esta versión está diseñada para **lanzamiento rápido, validación comercial y presentación institucional**. La interfaz de capas del hero es conceptual; un visualizador anatómico 3D real se desarrollará como módulo posterior y no se presenta aquí como una función ya disponible.

## Tecnología

HTML, CSS y JavaScript sin dependencias de compilación.
